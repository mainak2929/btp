\chapter{Core Code of the Planner}
\label{app:code}

The two functions of \code{website/sip.js} that produce every number on the page. The Python
equivalents are \code{optimized\_cash\_buffer} in \code{sip/optimize.py} and \code{\_smart\_split}
in \code{sip/engine.py}.

\begin{lstlisting}[language=Java,caption={Target split (risk parity + maximum Sharpe, cushion)}]
function target(rows, liquid) {            // rows: monthly [nifty, gold, liquid]
  var win = rows.slice(-120);              // the latest 120 months
  var n  = win.map(r => r[0]),  g  = win.map(r => r[1]);
  var xn = win.map(r => r[0] - r[2]), xg = win.map(r => r[1] - r[2]);
  var vN = cov(n, n), vG = cov(g, g), cNG = cov(n, g);
  var sleeve = 1 - liquid, lo = 0.10 / sleeve,
      hi = Math.min(0.70 / sleeve, 1 - 0.10 / sleeve);

  // risk parity with two assets: wN * sigmaN = wG * sigmaG
  var sN = Math.sqrt(vN), sG = Math.sqrt(vG);
  var rp = clip(sG / (sN + sG), lo, hi);

  // max Sharpe on returns above liquid: grid of 2,001 shares, then refine
  var eN = mean(xn), eG = mean(xg);
  function sharpe(w) {
    var m = w * eN + (1 - w) * eG;
    var v = w*w*vN + 2*w*(1-w)*cNG + (1-w)*(1-w)*vG;
    return m / Math.sqrt(v);
  }
  var ms = bestOf(sharpe, lo, hi);         // grid search + golden-section refinement

  var nShare = 0.5 * rp + 0.5 * ms;
  return [sleeve * nShare, sleeve * (1 - nShare), liquid];
}
\end{lstlisting}

\begin{lstlisting}[language=Java,caption={This month's purchases (smart split and 5\% band)}]
function plan(h, amount, w) {              // h: holdings [nifty, gold, liquid]
  var total = h[0] + h[1] + h[2] + amount, gap = [], need = 0;
  for (var k = 0; k < 3; k++) { gap[k] = Math.max(w[k]*total - h[k], 0); need += gap[k]; }
  var buy = gap.map((x, k) => need >= amount ? x / need * amount
                                             : x + w[k] * (amount - need));
  var after = h.map((x, k) => x + buy[k]);
  var drift = Math.max(...after.map((x, k) => Math.abs(x / total - w[k])));
  var trade = drift > 0.05 ? w.map((x, k) => x * total - h[k])   // reset to target
                           : buy;                                  // buy only
  return { buy: buy, drift: drift, trade: trade };
}
\end{lstlisting}

\chapter{Reproducibility}
\label{app:repro}

All code, data and results are in the project repository. Running \code{python run\_all.py} rebuilds
every table and figure in this report from the raw files, and \code{python -m pytest} runs 33
automated checks, including the absence of look-ahead in every strategy and the agreement between
the website and the Python engine.
